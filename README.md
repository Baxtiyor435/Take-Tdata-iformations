# 📊 TData Collection (Educational)

> ⚠️ DISCLAIMER  
This project is for **education, cybersecurity training, and awareness only**.  
No real user data is collected.  
All data used is **fake / simulated**.

---

## 🧠 Project Description

**TData Collection** demonstrates how attackers *attempt* to collect data  
and how defenders **detect, prevent, and log** such attempts.

Focus:
- Understanding data flow
- Learning detection methods
- Improving security awareness

---

## 🎯 Goals
- Simulate data collection techniques (mock data)
- Analyze logs & traffic
- Learn prevention strategies
- Practice blue-team skills

---

## 🧪 What Is Collected (Simulation)
- 🧑 Fake usernames & passwords
- 🌐 Request metadata (IP, User-Agent)
- ⏱️ Timestamped access logs
- ❌ No real personal data

---

## 🛡️ Defensive Perspective
This project teaches how to:
- Detect suspicious requests
- Block malicious behavior
- Log and analyze attempts
- Apply OWASP recommendations
